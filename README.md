# Sites que mais uso 🕖📜⬆️
Fiz uma lista simples dos sites que uso com suas respectivas imagens e também com o link de cada um. Fiz esse projeto utilizando o HTML (Linguagem que os navegadores utilizam) para visualização e um compartilhamento mais fácil.
Neste projeto criei 2 pastas, uma para guardar as imagens que são utilizadas no código para serem exibidas no site. E a outra para demonstrar o código dentro do VScode e o print do site na web funcionando.
